# Changelog

## 0.1.4 (2026-11-02)

- Shorts: the Shorts tab on channel pages is hidden, and a channel's Shorts page goes to the channel's home page.
- Comments now also hides live chat on live streams and the "Live chat" card under the video. The option is renamed "Comments and live chat".

## 0.1.3 (2026-11-02)

- Fixed: the Shorts entry in the wide sidebar showed again in 0.1.2. Its link has a title but no address, so both are now matched.

## 0.1.2 (2026-11-02)

- The Shorts button in the narrow sidebar is now hidden. YouTube had moved its label onto the link inside it.
- Opening the Shorts tab (youtube.com/shorts) goes to the home page instead of playing a random Short.

## 0.1.1 (2026-11-02)

- Comments are now also hidden in the side panel some YouTube layouts show next to the video.

## 0.1.0 (2026-11-02)

First release.

- Hides home page recommendations, related videos, Shorts, comments, end-of-video suggestions, and autoplay. Each can be turned on or off.
- Opens Shorts links in the normal player.
- Breaks: shows everything for a set number of minutes, then turns focus mode back on.
- Schedule: focus mode only on chosen days and hours, including overnight ranges.
- Settings sync across signed-in Chrome browsers.
